# SEC-001 AssetWatch

## Vision

AssetWatch is a security-oriented asset inventory tool.
It helps organize and analyze asset information through an incremental engineering approach.

## Current Version

v0.1

## Current Capability

- Read asset list from a local file

## Input

Text file containing asset information.

Example:

asset-01
asset-02
asset-03

## Output

Display loaded assets.

## Roadmap

v0.1 - Read asset list

v0.2 - Data cleanup and normalization

v0.3 - Input validation

v0.4 - Filtering and searching

v1.0 - Generate asset inventory report
